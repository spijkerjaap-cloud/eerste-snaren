# Eerste Snaren

Een kleine beeldende gitaar-leerapp voor Bo. De app begint bij les 1 met de basis: gitaar vasthouden, snaren herkennen en rustig luisteren naar losse snaren.

## Online zetten met GitHub Pages

1. Maak op GitHub een nieuwe repository, bijvoorbeeld `eerste-snaren`.
2. Upload `index.html` naar de root van die repository.
3. Ga in GitHub naar **Settings** → **Pages**.
4. Kies bij **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Klik **Save**.

Daarna geeft GitHub een link zoals:

`https://jouw-gebruikersnaam.github.io/eerste-snaren/`

Open die link op Bo's telefoon. Op iPhone kan ze daarna in Safari kiezen voor **Delen** → **Zet op beginscherm**.
